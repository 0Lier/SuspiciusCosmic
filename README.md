# SuspiciusCosmic

Plugin para mi servidor de Minecraft con amigos.

Este plugin revisa y mide la inactividad de los jugadores basándose en su movimiento respecto a un punto de referencia.

## Comandos y Uso

- `/sospechoso [jugador]`: Revisa la inactividad de un jugador (cuánto se ha movido desde su punto de referencia)
- `/suspiciuscosmic`: Comandos del plugin (recargar, etc)

---
Nota: Parte del código fue implementada utilizando vibecoding.
